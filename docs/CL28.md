# CL28: what changed in which kit script, and for whom

Removed because they rebuilt an existing script (the owner, 2026-11-23: "delete anything you built that replaced a script"):

- **`kit.py brief`**: repeated `kit.py resume`. Gone; the guard and every guide now name `resume`.
- **adopt's own ArtifactData batches**: bypassed `kit.py artifact load` / `push`. Adopt now starts the local board as
  `artifact load` does, writes there, then calls `artifact push`.
