# CL37: token usage before and after the board's update, and the usage ledger

Measured from the platform's own record of every Harmonize cloud session (claude-code-remote `get_session`:
`external_metadata.usage` = input, output, cache read, cache write tokens and `cost_usd`), 254 sessions with usage
out of 289 listed, 2026-11-14 to 2026-11-24. Nothing here is estimated. The rows are in `docs/CL37-sessions.jsonl`
(titles, times, roles, tokens, cost; no prompt or message text), and every table below is rebuilt by
`python3 -I scripts/usage.py compare --before 2026-11-23T00:27:22+00:00 --after 2026-11-23T01:25:19+00:00 --rows docs/CL37-sessions.jsonl --only`.

## The cut

The board's update = Harmonize moving onto the kit's Artifact board page and the kit's scripts and hooks:
`d3571da` 2026-11-23 00:27 UTC (the kit's board page built for Harmonize's Artifact), `90ec38d` 01:10 (the kit's
scripts in `.kit/`, Artifact mode), `b15d577` 01:25 (`install.py --update` from the kit, nothing of Harmonize's kept
back). **Before** = sessions started at or before 00:27; **after** = sessions started at or after 01:25 (the 58
minutes between are in neither). Orchestrators O40-O48 are before; O49-O53 after (O49 is the session titled
"Harmonize orchestrator (started by the clerk)", 01:28). No orchestrator ran between O48's end (2026-11-20 08:00)
and O49.

## What changed

- **A part costs less**: median $10.20 a part session before (n 107) against $7.52 after (n 20), -26%; output
  tokens -35%, cache read -31%, wall time -57%. Like with like (board and kit parts): $10.43 (n 10) against $6.92
  (n 19), -34%. The after parts are shorter steps (the CL train cuts work smaller), so part of this is the step
  size, not the board.
- **An orchestrator costs more**: median $24.04 (O40-O48) against $40.32 (O49-O53), +68%; output 119k against
  207k (+74%); per hour $3.3 against $6.3. It ran ~20 parts a day instead of ~11, so per part the orchestrator and
  clerk cost $9.93 against $7.30 (+36%). Contexts end lower (O52 263k, O53 346k, against ~400k before): the 380k
  hand-over holds.
- **The whole project per part** is about the same ($22.63 against $25.69, -12%) while it spent $443 a day against
  $286: more parts a day, each a little cheaper.
- **Reviews stopped**: 15 review sessions in the before window ($106), none after. The kit's automatic reviews did
  not run as cloud sessions after the cut (or ran under titles this does not see as reviews: none named CR- or review).
- **Clerks**: $1.38 a session before (n 26), $2.02 after (n 3): too few after to say.

## The ledger, from now on

`kit.py usage` (`.kit/usage.py`, installed by `install.py`), the hook `kit_usage.py` on Stop and SessionEnd: each
session's row from its own transcript (no model call, ~0.1 s), in `.kit/run/usage/` at once and on the branch
`kit-usage` (`usage/<date>.jsonl`, git plumbing: the working tree never changes) at SessionEnd, at `end_session.py`,
and at a Stop at most every 15 minutes. Its fields: input, output, cache read, cache write (5m/1h) tokens, cost,
API calls, owner turns, messages sent and received, tool calls by name, kit commands run, ArtifactData reads/writes
and their bytes, board CLI calls and bytes, subagents (type, model, tokens, cost), context peak, wall and active
time, compactions, model, Claude Code version, the kit commit in force (`.kit/manifest.json` `_kit_commit`), role
and part.
